# Neural Models Hands-on

This folder contains the complete Neural Models hands-on submission.

## Files
- `Code.py` - binary XOR, gradient check, zero-initialisation symmetry test, activation comparison, and three-class extension.
- `AI_Neural_Models_Report.pdf` - concise report with the required specifications, results, interpretations, and reflections.
- `prompt.txt` - exact LLM prompts used.

## Run
From this folder:

```powershell
python Code.py
```

If PyTorch is not installed:

```powershell
pip install torch numpy
```

A successful run ends with:

```text
ALL REQUIRED EXECUTABLE CHECKS PASSED.
```
